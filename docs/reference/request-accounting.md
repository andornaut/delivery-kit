# Request accounting

The request ledger, intake retention and closure evidence moved to coordination-kit in
delivery-kit 5.0. Coordination Kit 3.0 removed the legacy `ledger` commands and migrated open
requests into its store. See [Coordination Kit requests](https://github.com/andornaut/coordination-kit/blob/main/docs/reference/store.md#requests)
and [upgrading to Delivery Kit 5.0](../guides/upgrading.md#upgrading-to-50).
