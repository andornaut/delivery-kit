# Messages

Common role messages, their delivery guards, the Claude spool and reconciliation moved to
coordination-kit in delivery-kit 5.0. Coordination Kit 1.x kept the original `message`
commands. Coordination Kit 3.0 removed them. Use `msg` and `inbox` for store messages.

Reference: [coordination-kit messages](https://github.com/andornaut/coordination-kit/blob/main/docs/reference/messages.md),
[upgrading to 5.0](../guides/upgrading.md#upgrading-to-50).
