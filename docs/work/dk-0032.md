## Scope

Record each user request with a durable identity, owner, dependencies, an evidence-based
lifecycle, transition history and intake coverage, through the existing orchestration.

## Criteria

- Every request has a durable identity, owner and lifecycle backed by evidence.
- Transitions keep their history.
- Intake covers every registered role.
