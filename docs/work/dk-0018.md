## Scope

Extract the registry, messages, transports, harness adapters, request ledger, work protocol and
enrollment into a new coordination kit 1.0, which also gets the work-file check and report
commands. delivery-kit 5.0 depends on it.

## Criteria

- delivery-kit declares the coordination-kit version range it supports, and its pin guard checks
  that range at runner start.
- Work plan artifacts keep their hash and gain optional `path` and `commit` fields that point at
  the repository work file, with no schema generation change.
- The work-file report joins work-file milestones with live protocol state.

## Decisions

- Protocol work reference `dk-coordination-split`.
- The coordination kit's role, session, worktree and repository are created first, by
  game-coordinator.
- The coordination-kit backlog moves to the new kit's repository with the split.
