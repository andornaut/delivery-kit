## Scope

Refactor the source for project structure, encapsulation and simplification.
Modules expose small, explicit interfaces and the import graph has no cycles.
Pure functions separate decisions from I/O where practical. Behaviour, the CLI,
the package exports, configuration, state and event formats stay unchanged.

## Criteria

- No import cycles in `src/` or `scripts/`, verified by a check.
- Each module exports only what other modules or tests use.
- Decision logic that does not need I/O is in pure functions with direct tests.
- The containerized gate passes with the same contract cases.
