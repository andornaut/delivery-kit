## Scope

The Claude channel consumer's message guard opens one message-store attempt index per drain
instead of building a full message summary for every spool entry under `unblock.lock`.

## Criteria

- The guard rereads only the selected record and keeps every source, revision, binding,
  decision clearance and readiness recheck before claiming an entry.
- An entry whose parent message is `handled` or `superseded` is skipped without a claim or
  another store scan.

## Decisions

- A terminal message takes no further attempt, so its entry stays blocked and unclaimed.
  Retiring such entries is [dk-0009](dk-0009.md).
