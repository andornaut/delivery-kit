## Scope

Pin coordination-kit 1.0.1, which carries the event delivery contract cases, raise the supported
range to `>=1.0.1 <2.0.0` and remove those cases from delivery-kit's contract suite, keeping the
runner-side event cases.

## Criteria

- The devDependency pins the coordination-kit 1.0.1 release asset, and the lockfile records its
  integrity.
- `COORDINATION_KIT_RANGE` is `>=1.0.1 <2.0.0`, and every doc and test that states it matches.
- Each removed claude-events, codex-events and events delivery case has a corresponding case in
  coordination-kit 1.0.1.
- The contract suite keeps the events that load-blocked and gate-failed departures record, and
  one observer flush per virtual minute under the event dispatch lock.

## Decisions

- Protocol work reference `dk-coordination-kit-1-0-1`.
- Completes [dk-0018](dk-0018.md)'s decision to keep the event delivery cases until
  coordination-kit carries them.
- A patch release: runtime, CLI, exports and formats are unchanged. A game reinstalls
  delivery-kit 5.0.1; game-coordinator's coordination-kit pin may stay on 1.0.x.
