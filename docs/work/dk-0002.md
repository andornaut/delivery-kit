## Scope

The message transport maps the adapter receipts `deduplicated` and `unchanged` to explicit
results with diagnostics.

## Criteria

- `deduplicated`: the transport reports `accepted` with a `deduplicated` diagnostic and sends
  nothing new.
- `unchanged`: nothing is sent and the message stays `blocked` with an `unchanged` diagnostic.
- Both diagnostics use classification `guarded` and stage `receipt`.

## Decisions

- A deduplicated receipt proves the recipient already holds that exact request, so it counts as
  accepted. An unchanged receipt proves only that nothing was sent, so it stays blocked.
