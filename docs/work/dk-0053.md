## Scope

Measure and improve one recurring Delivery Kit operation while preserving its
current contracts, limits and failure handling.

## Criteria

- Compare the same representative workload before and after the change.
- Verify correctness at the affected boundary and pass the integration checks.
- Leave consumer configuration and live operations with their owners.

## Decisions

## Outcome

Observer adoption skips parsing event lines that cannot carry a start record.
It still handles escaped event types, byte offsets and incomplete appends.
On 11 paired samples of a synthetic log near the rotation threshold, median
status-report time fell from 4.97 ms to 2.89 ms, excluding CLI startup. A
fixture with Unicode escapes on every unrelated line was about 10% slower.
