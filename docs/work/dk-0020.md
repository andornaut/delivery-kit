## Scope

Record where the supported coordination-kit range is enforced. This replaces the dk-0018 criterion
that the runner checks the range at startup.

## Criteria

- `COORDINATION_KIT_RANGE` in `src/bus/pin.ts` is the single declaration of the supported range.
- The package check fails the build when the bundled coordination-kit version is outside the range.
- The runner loads only its bundled copy, so it neither reads nor requires a game copy of
  coordination-kit. `status` reports `coordination_kit: {bundled, supported}`, and the startup
  records carry the bundled version.

## Decisions

- The check runs at build time because coordination-kit is bundled into `dist/cli.js`. A runtime check
  of a separately installed package would test a copy the runner never loads.

## Outcome

Shipped in 5.0.0 (ff87f77). The range became `>=1.0.1 <2.0.0` in 5.0.1 ([dk-0019](dk-0019.md)).
