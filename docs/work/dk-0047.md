## Scope

Apply the [shared source structure](https://github.com/andornaut/game-coordinator/blob/main/docs/game-policies.md#source-structure)
end state for kits. ESLint guards the layers in
[packaging](../design/packaging.md): imports point down only, type imports
included, and shipped code never imports `src/testing/` or `scripts/`.
`import-x/no-cycle` rejects runtime cycles in `src/`, `scripts/` and `tests/`.
Type-only cycles are allowed only within one layer. With no known violations,
remove `scripts/imports.test.ts`. Lock `eslint-plugin-import-x` at 4.18.1.

## Criteria

- ESLint fails on an upward or sideways import, runtime or type-only, between
  layers, and on shipped code importing support code. Temporary violations in
  a scratch tree confirm each rule.
- `scripts/imports.test.ts` is removed and no permanent import-check test
  remains.
- The containerized gate passes with the contract cases unchanged.
