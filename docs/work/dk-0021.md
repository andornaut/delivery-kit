## Scope

Pin coordination-kit 1.0.2, which lists recipient message status from one snapshot and protocol
read view, and release delivery-kit 5.0.2 bundling it.

## Criteria

- The devDependency pins the coordination-kit 1.0.2 release asset, and the lockfile records its
  integrity.
- `COORDINATION_KIT_RANGE` stays `>=1.0.1 <2.0.0`, which contains 1.0.2.
- The README, upgrading and runner docs name delivery-kit 5.0.2 and coordination-kit 1.0.2 where
  they describe the current pin.
- `VERSION`, `package.json` and `package-lock.json` state 5.0.2.

## Decisions

- Protocol work reference `dk-5-0-2`.
- A patch release: delivery-kit's runtime, CLI, exports and formats are unchanged. A game only
  reinstalls delivery-kit 5.0.2.

## Outcome

Shipped in 5.0.2.
