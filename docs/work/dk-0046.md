## Scope

Extend cycle detection to every TypeScript and JavaScript module in `src/`,
`scripts/` and `tests/`, with type-only imports counted as edges. Extend the
ESLint `import-x/no-cycle` rule from `src/` to `scripts/` and `tests/`.

## Criteria

- `scripts/imports.test.ts` rejects any cycle in `src/`, `scripts/` or
  `tests/`, type-only edges included, and a synthetic type-only cycle fails it.
- ESLint reports a cycle in any of the three trees.
- The containerized gate passes with the contract cases unchanged.
