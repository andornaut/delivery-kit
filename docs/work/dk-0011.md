## Scope

Enrollment scope resolution, `protocol enroll`, `protocol boundary` and the enrollment report.

## Criteria

- Scope resolution reads each role journal, the registry and the request ledger once, with the
  ledger projection and events from one replay.
- `protocol enroll` and `protocol boundary` recheck only the selected role's journal, registry
  entry and effective binding; a change refuses with `enrollment-source-changed`.
- A receipt's inspection registry revision may precede unrelated registry writes but not exceed
  the current revision.

## Decisions

- Other roles' concurrent enrollments and publications never refuse an enrollment, report or
  boundary.
