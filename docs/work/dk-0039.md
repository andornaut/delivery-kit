## Scope

Remove unused internal code while preserving release packaging, source verification
and the live runner contracts. Record any compatibility tradeoffs separately.

## Criteria

- Remove helpers that have no production caller and the tests that only exercise them.
- Preserve the exact release controller and gate verification paths.
- Isolated checks and exact main CI pass.

## Decisions

- D1 (user, 2026-11-22; answers q-delivery-kit-0039-legacy): Retire old CLI redirects and automatic 6.0 outbox import in the next major. Keep 6.1.2 as the bridge for unmigrated installs.
- D2 (user, 2026-11-22; answers q-delivery-kit-0039-name): Make coordinator configuration the source of game display names. Stage removal of reports.project with compatible reader and rollback support.
- D3 (user, 2026-11-22; answers q-delivery-kit-0039-wrappers): Retire the three shell wrappers after checking callers. Keep equivalent npm and Make commands.

## Outcome

Removed unused host verification code and stale internal helpers. The live packer
keeps exact source validation and its offline container. CI classification now has
one implementation, and the runner still checks the pin before both departure paths.

The 8.0 source retires old CLI redirects and automatic outbox import. An unmigrated
outbox blocks startup with the 6.1.2 upgrade path. The npm and Make commands replace
the removed shell wrappers. Reports use the coordinator display name while older
pins still require the legacy config field. Field removal needs the Coordination Kit
validator and adoption of compatible readers.
