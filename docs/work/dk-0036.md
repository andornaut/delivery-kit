## Scope

Expose the exact verified SHA using the runner event stream. Preserve the existing
candidate, gate, push, CI and deploy events. Coordination Kit owns notification
aggregation and failure routing.

## Criteria

- Record the exact SHA only after immutable source verification, before gate execution.
- Identify a docs-only pinned push separately from a verified gate snapshot.
- An idle slot, stale request or failed capture has no capture evidence for that attempt.
- Preserve attempt identity, event history, admission, cadence and exact outcome evidence.
- Verify compatibility with the supported Coordination Kit reader before adoption.

## Decisions

## Outcome

The 7.1.0 runner emits schema-1 capture evidence. Coordination Kit 3.1.0 ingests it without an
extra notice. See the [runner event contract](../reference/runner.md#event-log).
