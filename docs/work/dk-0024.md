## Scope

Keep a crashed path-classification job from skipping the build, test, contract and package jobs.

## Criteria

- The skippable jobs run unless the `changes` job explicitly reports a docs-only push.
- The runner and configuration docs state that a path-filtered workflow lists its classification
  job in `requiredNames`, because a skipped required run counts as passing.

## Decisions

- The workflow condition is `!cancelled() && needs.changes.outputs.code != 'false'`; the runner's
  CI evaluation is unchanged.
