## Scope

Set a 4 GiB memory ceiling for the local release packer and the hosted release
cache warmer. Preserve their existing CPU settings and the game gate configuration.

## Criteria

- Both packaging launchers pass `--memory 4g`.
- The local pack check covers the Docker argument and exact source provenance.

## Decisions

## Outcome

The release packer and hosted cache warmer enforce the cap at container creation.
