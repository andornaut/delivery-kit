## Scope

Phase 2 of the coordination simplification plan: the runner appends typed events to
`var/games/<g>/bus/events.jsonl` and coordination-kit ingests them.

## Criteria

- Typed appends (`attempt`, `gate`, `push`, `ci`, `deploy`, `runner.started`) by the runner as the
  only writer, as atomic lines; a failed append never stops a departure.
- `complete` becomes a projection with a unique `(game, complete, sha)` key and is still delivered
  as a message to `reports.recipient`.
- An ingest cursor file in `bus/` lets `status` report drained without reading the store; a torn
  last line is quarantined; the log rotates after ingest.
- Rolling back to 6.0 converts uningested lines into outbox files.
