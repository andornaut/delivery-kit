## Scope

Split delivery-kit CI into jobs, and make the runner handle a docs-only departure range.

## Criteria

- Lint always runs. Build, test, contract and package jobs run only when a path outside
  `docs/**` changed. The AI attributions workflow is unchanged.
- The CI watch accepts a `skipped` required job as passing.
- A docs-only range gets no gate container: it is pushed, watches the light CI and is not
  deployed.
- A docs-only tip can be release-tagged because it has a green run.

## Decisions

- Protocol work reference `dk-docs-ci`.
- The same job split in each game's workflow is that game Tech's work, coordinated by
  game-coordinator.
