## Scope

Organize the busiest source areas by responsibility. Prefer small, explicit
interfaces and consistent naming while keeping the existing import layers.

## Criteria

- Keep each directory focused on a cohesive responsibility and keep its tests
  close to the code they exercise.
- Give callers clear entry points and keep implementation details behind them.
- Preserve the public CLI, package exports, state and runner behaviour.
- Pass the import graph checks and the full isolated gate on the integrated tree.

## Outcome

The runner entry point wires separate departure, post-push and observation
modules. Their tests follow the modules. A shared worktree removal operation
serves both departure and deployment. The source layer check resolves paths
from nested modules and covers type-only imports and re-exports.
