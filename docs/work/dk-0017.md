## Scope

Report a resident runner whose identity differs from the last adopted one.

## Criteria

- On startup, a runner whose identity token differs from the last adopted one emits a reporter
  event to its bus owner.
- `status --game ID` shows observer adoption as `current` or `stale`.

## Decisions

- Protocol work reference `dk-runner-supervision`; ships with [dk-0016](dk-0016.md), so a
  supervised restart is reported to the owner who re-adopts it.

## Outcome

Shipped in 4.7.0. A changed resident token emits one `resident-identity-changed` event through the reporter path when the protocol is active, and `status` reports `observer_adoption` as `current`, `stale` or `unknown` with a reason.
