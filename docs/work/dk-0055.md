## Scope

Apply the shared CLI conventions from Coordination Kit work item ck-0071 to
Delivery Kit's app delivery commands.

## Criteria

- Print scoped help without resolving the workspace.
- Accept both root forms before the option terminator and reject duplicate roots.
- Give safe usage guidance on stderr with the existing exit code.
- Accept app scopes for status and preserve existing selectors and JSON shapes.

## Outcome

Command help, root parsing and usage guidance follow the Coordination Kit
conventions without a dependency bump. Status accepts `--scope app:ID` and bare
app IDs through `--scope ID`. The existing selectors retain their report shapes.
