## Scope

Document existing work definition and receipt rules in the work protocol reference.

## Criteria

- A work receipt binds the exact `definitionHash`. Republishing changed content requires
  `replaces` and starts with no receipts or accepted submissions.
- With a `source` pin, every `execution` and `check` receipt carries an equal `source`, or it is
  refused with `receipt-source-mismatch`.
- `before-cleanup` and `cleanup` require a nonempty artifact in `definition.artifacts` whose
  hash differs from `definition.plan`.

## Decisions

- Documentation of current behaviour only; no code change.
