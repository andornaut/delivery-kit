## Scope

The runner stops bundling scheduled review delivery and event delivery. For each due review slot
it spawns the coordinator-installed `coordination-kit review deliver`, and for each event flush
`coordination-kit events flush`, and reads one typed JSON result from each. Release delivery-kit
6.0.0.

## Criteria

- The runner spawns the coordinator root's
  `node_modules/@andornaut/coordination-kit/dist/cli.js` with the running Node binary and
  `--root`, never `npx`, with a 45 s timeout and a process-group kill on timeout or abort. A spawn
  never holds `departure.lock` and never delays a departure.
- A missing CLI, a nonzero exit, a malformed or mismatched result, a timeout or an abort claims
  no delivery, is logged and never stops the runner or a departure.
- The CLI version in each result must satisfy `COORDINATOR_CLI_RANGE` (`>=1.2.0 <2.0.0`) in
  `src/bus/pin.ts`; an out-of-range CLI defers reviews and flushes with reason `cli-version`.
- Each changed CLI identity is logged and recorded in `bus/seam.json`; `status --game` reports it
  as `coordinator_cli`.
- The `bus: scheduled review <slot>: <detail>` line and the stderr deferral line keep their
  prefixes. The observer pass order, minute-start wake, no replay and once per slot per pass are
  unchanged.
- Events are still recorded in-process; only delivery moves to the CLI. The bundle no longer
  imports `deliverScheduledReview`, `DEFERRED_PREFIX` or `flushEvents`, and the package check
  asserts that `dist/` imports only `node:` builtins.

## Decisions

- Protocol work reference `dk-6-0`.
- A major release: a 6.0 runner on a coordinator root without coordination-kit 1.2 defers reviews
  and event delivery.
