## Scope

The migration plan inventory and original import accept per-recipient transport state under
`recipients/<conversation-uuid>/unblock/` in the legacy messages directory.

## Criteria

- Only top-level `<sha256>.json` records, with their `<sha256>.lock` files, are message
  originals.
- Receipts and their lock files, the channel `unblock.lock`, `claude-spool/` entries and
  `claude-delivered/` copies are copied byte-exact and never published as originals.
- After activation the transports read that state at the new root, so delivered and pending
  requests keep their receipts.
- Any other file there refuses import and activation with `invalid-migration`.

## Decisions

- Folded into 4.6.1 because the protocol switch needs it.
