## Scope

Each enrollment receipt is published with an `intake/enrollment-anchor` object in the same
transaction, recording the participant's known references at publication and the receipt
digest.

## Criteria

- A reference the receipt omits revokes representation and adoption only if it was known at
  publication.
- A reference first known later appears in `omitted` and `uncovered` and keeps
  `coverageComplete` false; the receipt stays represented and, when active, adopted.
- A receipt without a matching anchor keeps the strict rule. Generation, phase, binding, epoch
  and parent checks still mark a receipt stale.

## Decisions

- A role's own later work must not revoke its adoption and refuse its next boundary; the gap
  stays visible as uncovered.
