## Scope

Create the owned receipt directory automatically, report failures before admission accurately
without losing send uncertainty, and recover only fully verified completed compaction turns.

## Criteria

- A missing receipt directory is created by its owner before the first receipt write.
- A failure before admission is reported as such, and an uncertain send stays uncertain.
- Post-compaction recovery acts only on turns verified as complete.

- Filed with this convention after delivery; the approval predates the work-file convention.
