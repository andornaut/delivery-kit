# Request accounting

The request ledger, intake retention and closure evidence moved to coordination-kit in
delivery-kit 5.0. The `ledger` commands are `coordination-kit ledger ...` with the same options
and output.

Reference: [coordination-kit request accounting](https://github.com/andornaut/coordination-kit/blob/main/docs/request-accounting.md),
[upgrading to 5.0](upgrading.md#upgrading-to-50).
