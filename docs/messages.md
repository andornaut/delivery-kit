# Messages

Common role messages, their delivery guards, the Claude spool and reconciliation moved to
coordination-kit in delivery-kit 5.0. The `message` commands are `coordination-kit message ...`
with the same options and output.

Reference: [coordination-kit messages](https://github.com/andornaut/coordination-kit/blob/main/docs/messages.md),
[upgrading to 5.0](upgrading.md#upgrading-to-50).
